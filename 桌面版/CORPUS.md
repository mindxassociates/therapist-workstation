# 临床语言语料库（中文）

本文件说明咨询记录编辑框「常用句式」面板使用的临床语言语料库：它的结构与使用边界。语料库由临床医生提供的文档参考资料蒸馏整理而成（2026-10），只保留可复用的临床书面句式，不包含任何个案信息。

## 目的

手写咨询记录时，表述容易口语化或句式单调。语料库把规范的临床书面语拆成带槽位的句式（句中〔〕为槽位，须按实际内容填写），供书写时点选插入，例如多使用「协助、探讨、促进、处理、强化、肯定、正常化、提供心理教育」等表达，并统一采用第三人称。

语料库只影响**怎么写**，不影响**写什么**：它不得成为添加内容的理由（见「使用边界」）。

## 结构

语料库（代码中为 `CORPUS_ZH`，位于 `web/index.html`）分七个部分，在句式面板中逐组列出，点击任意句式即插入当前字段的光标处：

| 部分 | 内容 |
| --- | --- |
| 呈现 | 来访者本次报告的问题/症状、情绪状态、生活事件与压力源、神情与开放程度 |
| 评估与进展 | 觉察提升、持续进展、技巧迁移、新领悟、症状减轻，以及「仍存在困难、改变尚未稳定」等如实表述 |
| 干预·通用 | 不分取向的常用干预句式：积极倾听与反映、识别触发因素、探讨早年经历/家庭模式影响、心理教育、行动计划、正常化、强化应对、检验负面想法、角色扮演、教授并练习技巧 |
| 干预·按取向 | 按流派分组的干预句式（DBT／辩证行为、动机式访谈、心理动力学、创伤知情、成瘾／物质使用、CBT／认知行为、行为取向、家庭／系统、支持性／人本），在面板中逐组列出，按需取用 |
| 问题句式 | 按来访者问题分组的句式（11 组，每组 4 条：焦虑、抑郁、愤怒管理、哀伤与丧失、强迫、关系冲突、自尊与自我价值、家庭冲突、亲职与育儿、惊恐与恐惧、物质使用），在面板中以「问题句式：<问题>」为标题逐组列出 |
| 反应 | 来访者对干预的开放程度、领悟、部分进展、练习后的变化与仍需支持之处 |
| 计划 | 课后练习与记录、下次咨询主题、课后作业、维持计划与评估进展、症状加重时的应对/安全步骤 |

## 我的句式（收藏与自建）

常用句式面板顶部的置顶区「★ 我的常用」汇集咨询师自己的句式：

- **收藏**：任意句式右侧有 ☆/★ 开关，点击即收藏到置顶区（或取消收藏）。收藏的是句式文本本身。
- **自建**：在置顶区的输入框输入惯用句式并点「添加」即可加入；自建句式可逐条删除（×）。
- **存储**：收藏与自建分别保存在本机偏好 `aiFavPhrases`、`aiCustomPhrases`（均为文本数组），与程序的其他偏好走同一套本地持久化，不写入咨询记录正文。

## 使用边界

- 仅在与本次咨询内容相符时，才取用语料库句式；
- **不得添加实际咨询中没有发生的干预、症状、风险判断或进展**——语料库列出某种干预或某种进展，不表示它在本次咨询中实际发生过；
- 槽位内容必须按实际情况填写，不得照抄槽位提示文字充当记录内容。
