# 临床语言语料库（中文）

本文件说明「智能记录」生成咨询记录草稿时使用的临床语言语料库：它的结构、匹配方式与使用边界。语料库由临床医生提供的文档参考资料蒸馏整理而成（2026-10），只保留可复用的临床书面句式，不包含任何个案信息。

## 目的

本地模型生成的草稿容易出现口语化、表述不稳定或句式单调的问题。语料库把规范的临床书面语拆成带槽位的句式（句中〔〕为槽位，须按实际内容填写），注入生成提示，使草稿在**用词与句式**上自动靠拢标准临床书面语，例如多使用「协助、探讨、促进、处理、强化、肯定、正常化、提供心理教育」等表达，并统一采用第三人称。

语料库只影响**怎么写**，不影响**写什么**：它不得成为添加内容的理由（见「使用边界」）。

## 结构

语料库（代码中为 `AI_CORPUS_ZH`，位于 `web/index.html` 的智能记录部分）分六个部分：

| 部分 | 内容 |
| --- | --- |
| 呈现 | 来访者本次报告的问题/症状、情绪状态、生活事件与压力源、神情与开放程度 |
| 评估与进展 | 觉察提升、持续进展、技巧迁移、新领悟、症状减轻，以及「仍存在困难、改变尚未稳定」等如实表述 |
| 干预·通用 | 不分取向的常用干预句式：积极倾听与反映、识别触发因素、探讨早年经历/家庭模式影响、心理教育、行动计划、正常化、强化应对、检验负面想法、角色扮演、教授并练习技巧 |
| 干预·按取向 | 按流派分组的干预句式，每次生成只匹配一组（见「取向匹配」） |
| 反应 | 来访者对干预的开放程度、领悟、部分进展、练习后的变化与仍需支持之处 |
| 计划 | 课后练习与记录、下次咨询主题、课后作业、维持计划与评估进展、症状加重时的应对/安全步骤 |

另有两条全局指引随语料库一并注入：

- **写作语体**：第三人称、正式临床书面语。
- **使用边界（警告）**：见下节。

## 取向匹配

「干预·按取向」按生成设置中填写的「取向 / 风格」文本匹配，只选一组。匹配按下列固定顺序逐组检查关键词（英文关键词不区分大小写，中英文均按子串匹配），命中第一组即停止：

| 顺序 | 分组 | 匹配键 |
| --- | --- | --- |
| 1 | DBT／辩证行为 | dbt、dialectical、辩证 |
| 2 | 动机式访谈 | motivational、动机 |
| 3 | 心理动力学 | psychodynamic、psychoanalytic、dynamic、动力 |
| 4 | 创伤知情 | trauma、ptsd、创伤 |
| 5 | 成瘾／物质使用 | addiction、substance、relapse、成瘾、物质 |
| 6 | CBT／认知行为 | cbt、cognitive、认知 |
| 7 | 行为取向 | behavioral、behavior、行为 |
| 8 | 家庭／系统 | family、system、couple、家庭、系统 |
| 9（默认） | 支持性／人本 | person-centered、humanistic、supportive、人本 |

顺序优先于文本中出现的先后：例如取向填写「创伤知情与 CBT」时，按顺序命中创伤知情组，而不是 CBT 组。未填写取向、或填写内容不含任何关键词时，默认使用支持性／人本组。

实现：`aiMatchCorpusModality(orientText)` 负责匹配，`aiCorpusGuidance(orientText)` 组装指引块。

## 在提示中的位置

生成提示由 `buildNotePrompt(source)` 组装，转写稿与简要小结两种输入模式共用同一路径，因此语料库对两种模式都生效。组装顺序为：

1. 系统指令（包含输出语言规则与「取向 / 风格」一行）；
2. 参考记录模板框架（选用了记录模板时）；
3. **临床语言语料库指引块**；
4. 用户自定义模板 / 指令（**最高优先级**，与语料库或记录格式冲突时以它为准）；
5. 待整理的转写稿或小结原文。

## 使用边界

- 仅在与咨询内容相符时，才优先采用语料库句式；
- **不得添加转写稿/小结中没有依据的干预、症状、风险判断或进展**——语料库列出某种干预或某种进展，不表示它在本次咨询中实际发生过；
- 槽位内容必须来自转写稿/小结本身，不得照抄槽位提示文字充当记录内容；
- 生成结果始终是草稿，须由咨询师核对、修改后才保存，语料库不改变这一流程。
