# 心理咨询师工作台 — 便携版使用说明

便携版**免安装**：把整个文件夹放在任何位置（电脑本地文件夹、移动硬盘或 U 盘），双击程序即可使用。所有数据（加密数据库、自动备份）都保存在本文件夹内的 `Data` 和 `Backups` 文件夹中，跟着文件夹走。

## 使用要点

1. **不要删除 `portable.mode` 文件**，也不要把程序单独移出文件夹——它决定数据保存在文件夹内。没有它，程序会改用这台电脑的固定数据目录，U 盘里的数据就「看不见」了。
2. **退出程序后再拔 U 盘 / 移动文件夹**，避免数据库写入被中断。
3. 数据是加密保存的，但**文件夹和 U 盘本身要保管好**：设置足够强的登录密码；介质丢失时，密码是最后一道防线。
4. **不要把便携文件夹放进云盘同步目录**（如网盘同步文件夹）——多台电脑同时同步同一个数据库会造成冲突，也可能构成个人信息出境风险。如需在两台电脑间迁移，用复制整个文件夹的方式，并确保复制时程序已退出。
5. Windows 便携版需要 WebView2 运行时（Windows 10/11 一般已自带）；若打开时提示缺少 WebView2，请改用安装版，或从微软官网安装 WebView2 后再运行。
6. macOS 便携版：请保持 `portable.mode` 与 `.app` 在同一文件夹内，不要把标记文件放进 `.app` 内部（会破坏应用签名）。首次打开仍需右键 →「打开」放行未签名应用。

## 升级

用新版本便携包解压到新文件夹后，把旧文件夹的 `Data` 和 `Backups` 两个文件夹复制过去即可（复制时两边程序都要已退出）。
