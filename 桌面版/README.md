# 心理咨询师工作台 Desktop V3.8.0

面向在中国大陆执业的心理咨询师：中英双语、本地优先、单机多账户。品牌色为 Mind X Provider Portal 的 `#4a778b / #355564`。

Tauri 2 + Web UI + 本地加密数据库的单机桌面版框架。

## V3.1 架构基线

- 单机使用，不提供局域网/云端实时同步。
- 支持多个本地账户；第一个账户自动为管理员。
- 管理员可创建、启用、停用其他本地账户。
- 至少保留一个启用的管理员账户，且不能停用当前登录账户。
- 所有本地账户共享同一个加密工作数据库，不为每个账户建立独立数据仓库。
- 每个账户使用自己的密码解锁同一数据库主密钥。
- 管理员/咨询师角色、自动锁定、密码修改、审计日志与完整性校验继续保留。
- 不要让两台电脑同时直接打开同一活动数据库。

## Windows 首次构建

### 已有环境
Node.js 22 和 Visual Studio 2022 Build Tools 可以继续使用。

### 还需要 Rust
在 PowerShell 中运行：

```powershell
winget install --id Rustlang.Rustup
```

安装后关闭 PowerShell，重新打开，再检查：

```powershell
rustc --version
cargo --version
node -v
npm -v
```

### 构建
解压项目，在项目目录打开 PowerShell：

```powershell
.\build-windows.bat
```

第一次 Rust/Tauri/SQLCipher 编译可能较慢。成功后安装程序位于：

```text
src-tauri\target\release\bundle\nsis\
```

## macOS 构建

在 Mac 上安装 Xcode Command Line Tools、Node.js 22 与 Rust（rustup）后，在项目目录运行：

```bash
chmod +x build-macos.command
./build-macos.command
```

产物位于 `src-tauri/target/release/bundle/`（`.app` 与 `.dmg`）。本项目产物**未签名**：在本机自用可直接打开（首次需在「系统设置 → 隐私与安全性」中放行）；如需分发给其他咨询师，须用 Apple Developer ID 签名并公证（notarization），否则对方 Mac 会拦截。

数据位置（标准模式）：`~/Library/Application Support/us.mindx.therapistworkstation/` 下的 Data / Backups 文件夹；在 `.app` 同目录放置 `portable.mode` 文件则为便携模式。Windows 标准模式位于 `%LOCALAPPDATA%\us.mindx.therapistworkstation\`。

## 第一次运行测试

1. 只使用虚拟来访者数据。
2. 创建第一个管理员账户。
3. 进入“安全与审计”，创建第二个“咨询师”测试账户。
4. 锁定并使用第二个账户登录，确认能看到共享的工作数据。
5. 确认咨询师看不到用户管理功能。
6. 使用管理员重新登录，确认可以停用测试咨询师账户。
7. 测试自动锁定、修改密码、审计日志和完整性校验。
8. 测试备份后完全退出并重新打开应用，确认数据可正常解锁。

正式录入真实资料前，应完成 Windows 实机运行、备份恢复和异常退出测试。

## 隐私合规（中国大陆）

工作台按《个人信息保护法》对敏感个人信息的处理要求设计：本地加密存储、不上云、单独同意清单项、本地多账户与审计、来访者数据导出与彻底删除、每日加密备份。应用内「隐私与合规」页有完整说明与可打印的《个人信息处理告知》模板。本节与应用内说明均为产品功能说明，不构成法律意见。

## 个性化设置

主题色（8 种预设 + 自定义取色，默认品牌色 `#4a778b` 门户蓝灰）、浅色 / 深色主题、字号（小 / 标准 / 大）、界面密度（舒适 / 紧凑）、标题栏风格（极光渐变 / 纯色 / 浅色）、登录后默认打开页面、首页模块显示开关（今日日程 / 今日咨询 / 今日待办 / 待收费 / 建档未完成 / 待补记录 / 最近咨询），并可一键恢复默认外观。设置保存在工作区中，所有本地账户共享。

## 临床与运营功能

结合本地单机使用场景，本版加入：

* **本地化临床运营套件（V3.8.0 新增，对照 Sessions Health 并去除保险体系）**：表单中心（自定义表单构建器+分发/填写/签署状态+打印）、咨询记录签名锁定与附注、咨询提醒工作清单（微信话术一键复制）、服务项目与收费标准目录、受督记录、来访者 CSV 批量导入、日历 .ics 导入/导出。
* **中英双语界面**：顶栏右侧「中文 / EN」药丸切换；首次启动按操作系统语言自动选择（中文系统显示中文，其他语言系统显示英文），选择后记住。覆盖全部页面、对话框、提示与导出文档；量表题目采用国际标准英文表述；存储值与用户内容不翻译。
* **量表评估**：PHQ-9、GAD-7、SCL-90、SDS、SAS、PSQI 六种常用量表，逐题作答、自动计分与分级：SDS / SAS 含反向计分并换算标准分；SCL-90 给出总分、阳性项目数与十因子分；PSQI 按七个成分计分。PHQ-9 第 9 题、SCL-90 第 15 题阳性自动提示关注自伤风险；来访者档案内可看历次分数与较上次变化；「量表评估」页有**分数趋势线**（按来访者与量表成图，标明首测→最近的变化），档案页量表区也有迷你趋势线。答题时分数**实时自动计分**并显示分级，不必等保存。
* **危机风险评估**：结构化记录风险等级（低 / 中 / 高 / 紧急）、危险因素、保护因素、处置与安全计划及随访日期；「需关注」列表汇总临近 / 逾期的随访与量表风险阳性个案；页面内置国内危机热线（12356 等）。档案原有的「风险与转介」快捷标记继续保留。
* **伴侣 / 家庭个案**：来访者档案可设定个案类型并关联其他来访者为个案成员；写咨询记录时勾选本次出席成员，记录列表中一并显示。
* **团体咨询**：独立页面管理团体（成员、开始日期、每期收费），逐期记录主题、出席与内容，并可为出席成员一键生成待收款收费记录。
* **开票信息**：来访者档案保存开票抬头、税号与备注；收费记录带开票状态（无需 / 待开票 / 已开票）与发票号；对账单自动带入开票信息。
* **微信话术**：日程与待收款记录处可打开话术库（预约确认、咨询前提醒、改期协商、爽约跟进、缴费提醒、首次咨询须知），自动带入姓名、时间与金额，一键复制后粘贴到微信发送（内容可先修改）。
* **候补名单**：登记等待空缺的潜在来访者（议题、期望时段、来源），按状态分组管理，可一键转为正式来访者档案。
* **日程状态与着色**：日程可标记已确认 / 已完成 / 爽约 / 迟到取消 / 已取消，月历按状态着色；可记录视频会议链接。
* **收费对账单**：按来访者与时间段生成对账单（咨询次数、收费明细、应收 / 已收 / 未收），可打印或存为 PDF。
* **数据洞察**：咨询场次、实收与待收、爽约与迟到取消统计、咨询量 Top 来访者；近 6 个月**收入趋势线**（实收与应收双线折线图，带数值标注）。
* **文档追踪**：在来访者档案中记录知情同意书、个人信息处理告知、量表等文件的待签署 / 已签署 / 已发送状态。
* **默认收费标准**：为每位来访者设置默认收费，新建收费记录时自动带入。
* **写记录带上次回顾**：打开咨询记录时，顶部自动显示这位来访者上次的安排 / 主题 / 风险记录与最近量表分数；记录方式默认沿用上次的选择；保存新记录时可一并生成收费记录（默认勾选，金额取默认收费，同一天同金额不重复生成）。
* **每周重复日程与改期**：新建日程可选「每周重复，共 N 周」，一次排好固定咨询；已有日程有「改期」按钮（原日程自动标记已取消并注明去向）；月历与周视图里还能把日程直接拖到另一天改期（时间不变）。
* **爽约 / 取消后一键后续**：把日程改为爽约、迟到取消或已取消后，自动弹出后续处理——生成跟进任务，或打开微信脚本联系来访者重新安排。
* **量表趋势图**：档案的量表区为每种做过两次以上的量表画一条分数趋势线，一眼看出走势。
* **来访者时间线**：档案页按时间把咨询记录、量表、危机评估、风险标记与收费串成一条时间线，回顾个案进程不用逐页翻。
* **阶段小结一键汇编**：选一段时间，一键汇编出阶段小结初稿（咨询次数与议题、工作与变化、量表首末次对比、风险情况），在本机由已有数据拼成、可编辑，并可导出 PDF 或复制。
* **量表复测提醒**：进行中的来访者距上次量表评估超过 4 周，今日工作台自动提醒复测，并可一键新增评估。
* **快速跳转与快捷键**：任意页面按 Ctrl / Cmd + K 打开快速跳转（搜来访者或页面，回车直达）；对话框内按 Ctrl / Cmd + S 直接保存。
* **上手清单**：新用户今日工作台有五步上手清单（建档 → 排咨询 → 写记录 → 做量表 → 备份），完成自动打勾，全部完成自动消失，也可手动关闭。
* **侧边栏常用置顶**：「个性化设置」里勾选常用页面，侧边栏顶部出现「常用」区，一键直达。

## 模板系统

模板按用途分为三类：**咨询记录模板**（六字段记录框架）、**咨询方案模板**（目标 / 工作重点 / 频率 / 阶段 / 评估调整）、**通用模板**（两处都可套用）。

* 内置模板：首次咨询 / 初始评估、结构化咨询记录、SOAP 记录、阶段小结 / 结案小结、阶段性咨询方案、安全计划（危机干预），首次登录自动加入。
* V3.1.15 起新增一组实用内置模板：电话 / 线上简短沟通记录、危机干预记录、个案概念化、伴侣 / 家庭咨询记录、团体咨询记录、督导记录、转介记录（通用），均为带【】占位提示的可直接填写框架，老用户升级后自动加入。
* 内置与自建模板都可以**编辑、删除**；删除后不会被重复加入。
* 写咨询记录时可套用记录 / 通用模板；填写咨询方案时可套用方案 / 通用模板，套用后可继续修改。
* **脚本与句式（TextExpander 式快捷插入）**：咨询记录编辑框内有「脚本与句式」面板（内置中文临床语料按组折叠、可搜索）；更重要的是在任意记录框里直接打字调用——输入自己脚本的**快捷词**（如 hx），或输入 **/** 再打关键词搜索全部脚本与句式，弹出下拉后方向键选择、回车插入，〔〕空位自动选中待填。自己的脚本在面板里添加，可同时设置快捷词；「★ 我的常用」收藏照常可用。原微信话术统一改称**微信脚本**。
* **记录导出 PDF**：来访者档案页「导出记录 PDF」一键生成该来访者的完整记录文档（档案、咨询记录、量表、风险评估、目标、收费）；数据中心可一键导出全部来访者记录，在打印窗口选择「另存为 PDF」即得 PDF。
* **功能小提示**：量表计分、风险随访、团体收费、开票、审计校验、PDF 导出等功能旁有小小的 i 标记，悬停即可看到说明。
* **常用句式**：咨询记录编辑框内有「常用句式」面板（内置一套中文临床语言语料：呈现、评估与进展、干预·通用、干预·按取向、反应、计划，并按问题分组的问题句式：焦虑、抑郁、愤怒管理、哀伤与丧失、强迫、关系冲突、自尊与自我价值、家庭冲突、亲职与育儿、惊恐与恐惧、物质使用），点击任意句式即插入当前正在填写的字段光标处，并自动选中第一个〔〕槽位便于改写。
* **我的句式（收藏与自建）**：面板顶部有「★ 我的常用」区——点击任意句式右侧的 ☆ 即可收藏到这里，也可以输入并添加自己惯用的句式（自定义句式可删除）。收藏与自建句式保存在本机偏好中，供手工书写时优先取用。

## 品牌与文档版式（分享给来访者的 PDF）

* **上传工作室 Logo**：在「系统设置 → 机构与文档」上传 PNG / JPG（建议透明背景），自动压缩保存在本机；顶部品牌栏也会显示。

## 发行方式：安装版与便携版

桌面版只发布一个版本，两种打包形式，功能完全相同：

* **安装版**：通过安装程序安装到本机（Windows 安装包 / macOS .dmg），数据保存在系统应用数据目录。
* **便携版**：免安装，解压即用；数据保存在程序旁的便携文件夹中，适合 U 盘随身携带。
