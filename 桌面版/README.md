# 心理咨询师工作台 Desktop V3.1.16

面向在中国大陆执业的心理咨询师：中文、本地优先、单机多账户。品牌色为 Mind X Provider Portal 的 `#4a778b / #355564`。

Tauri 2 + Web UI + 本地加密数据库的单机桌面版框架。

## V3.1 架构基线

- 单机使用，不提供局域网/云端实时同步。
- 支持多个本地账户；第一个账户自动为管理员。
- 管理员可创建、启用、停用其他本地账户。
- 至少保留一个启用的管理员账户，且不能停用当前登录账户。
- 所有本地账户共享同一个加密工作数据库，不为每个账户建立独立数据仓库。
- 每个账户使用自己的密码解锁同一数据库主密钥。
- 管理员/咨询师角色、自动锁定、密码修改、审计日志与完整性校验继续保留。
- 不要让两台电脑同时直接打开同一活动数据库。

## Windows 首次构建

### 已有环境
Node.js 22 和 Visual Studio 2022 Build Tools 可以继续使用。

### 还需要 Rust
在 PowerShell 中运行：

```powershell
winget install --id Rustlang.Rustup
```

安装后关闭 PowerShell，重新打开，再检查：

```powershell
rustc --version
cargo --version
node -v
npm -v
```

### 构建
解压项目，在项目目录打开 PowerShell：

```powershell
.\build-windows.bat
```

第一次 Rust/Tauri/SQLCipher 编译可能较慢。成功后安装程序位于：

```text
src-tauri\target\release\bundle\nsis\
```

## macOS 构建

在 Mac 上安装 Xcode Command Line Tools、Node.js 22 与 Rust（rustup）后，在项目目录运行：

```bash
chmod +x build-macos.command
./build-macos.command
```

产物位于 `src-tauri/target/release/bundle/`（`.app` 与 `.dmg`）。本项目产物**未签名**：在本机自用可直接打开（首次需在「系统设置 → 隐私与安全性」中放行）；如需分发给其他咨询师，须用 Apple Developer ID 签名并公证（notarization），否则对方 Mac 会拦截。

数据位置（标准模式）：`~/Library/Application Support/us.mindx.therapistworkstation/` 下的 Data / Backups 文件夹；在 `.app` 同目录放置 `portable.mode` 文件则为便携模式。Windows 标准模式位于 `%LOCALAPPDATA%\us.mindx.therapistworkstation\`。

## 第一次运行测试

1. 只使用虚拟来访者数据。
2. 创建第一个管理员账户。
3. 进入“安全与审计”，创建第二个“咨询师”测试账户。
4. 锁定并使用第二个账户登录，确认能看到共享的工作数据。
5. 确认咨询师看不到用户管理功能。
6. 使用管理员重新登录，确认可以停用测试咨询师账户。
7. 测试自动锁定、修改密码、审计日志和完整性校验。
8. 测试备份后完全退出并重新打开应用，确认数据可正常解锁。

正式录入真实资料前，应完成 Windows 实机运行、备份恢复和异常退出测试。

## 隐私合规（中国大陆）

工作台按《个人信息保护法》对敏感个人信息的处理要求设计：本地加密存储、不上云、单独同意清单项、本地多账户与审计、来访者数据导出与彻底删除、每日加密备份。应用内「隐私与合规」页有完整说明与可打印的《个人信息处理告知》模板。本节与应用内说明均为产品功能说明，不构成法律意见。

## 个性化设置

主题色（8 种预设 + 自定义取色，默认品牌色 `#4a778b` 门户蓝灰）、浅色 / 深色主题、字号（小 / 标准 / 大）、界面密度（舒适 / 紧凑）、标题栏风格（极光渐变 / 纯色 / 浅色）、登录后默认打开页面、首页模块显示开关（今日日程 / 今日咨询 / 今日待办 / 待收费 / 建档未完成 / 待补记录 / 最近咨询），并可一键恢复默认外观。设置保存在工作区中，所有本地账户共享。

## 临床与运营功能

结合本地单机使用场景，本版加入：

* **量表评估**：PHQ-9、GAD-7 中文版，逐题作答、自动计分与严重程度分级；PHQ-9 第 9 题阳性自动提示关注自伤风险；来访者档案内可看历次分数与较上次变化。
* **候补名单**：登记等待空缺的潜在来访者（议题、期望时段、来源），按状态分组管理，可一键转为正式来访者档案。
* **日程状态与着色**：日程可标记已确认 / 已完成 / 爽约 / 迟到取消 / 已取消，月历按状态着色；可记录视频会议链接。
* **收费对账单**：按来访者与时间段生成对账单（咨询次数、收费明细、应收 / 已收 / 未收），可打印或存为 PDF。
* **数据洞察**：咨询场次、实收与待收、爽约与迟到取消统计、咨询量 Top 来访者、近 6 个月实收趋势。
* **文档追踪**：在来访者档案中记录知情同意书、个人信息处理告知、量表等文件的待签署 / 已签署 / 已发送状态。
* **默认收费标准**：为每位来访者设置默认收费，新建收费记录时自动带入。

## 模板系统

模板按用途分为三类：**咨询记录模板**（六字段记录框架）、**咨询方案模板**（目标 / 工作重点 / 频率 / 阶段 / 评估调整）、**通用模板**（两处都可套用）。

* 内置模板：首次咨询 / 初始评估、结构化咨询记录、SOAP 记录、阶段小结 / 结案小结、阶段性咨询方案、安全计划（危机干预），首次登录自动加入。
* V3.1.15 起新增一组实用内置模板：电话 / 线上简短沟通记录、危机干预记录、个案概念化、伴侣 / 家庭咨询记录、团体咨询记录、督导记录、转介记录（通用），均为带【】占位提示的可直接填写框架，老用户升级后自动加入。
* 内置与自建模板都可以**编辑、删除**；删除后不会被重复加入。
* 写咨询记录时可套用记录 / 通用模板；填写咨询方案时可套用方案 / 通用模板，套用后可继续修改。
* **常用句式**：咨询记录编辑框内有「常用句式」面板（句式与智能记录共用同一套中文临床语言语料：呈现、评估与进展、干预·通用、干预·按取向、反应、计划，并按问题分组的问题句式：焦虑、抑郁、愤怒管理、哀伤与丧失、强迫、关系冲突、自尊与自我价值、家庭冲突、亲职与育儿、惊恐与恐惧、物质使用），点击任意句式即插入当前正在填写的字段光标处，并自动选中第一个〔〕槽位便于改写。纯手工书写即可使用，不依赖 AI 组件，便携版同样可用。
* **我的句式（收藏与自建）**：面板顶部有「★ 我的常用」区——点击任意句式右侧的 ☆ 即可收藏到这里，也可以输入并添加自己惯用的句式（自定义句式可删除）。收藏与自建句式保存在本机偏好中，手工书写与智能记录生成都可优先取用。

## 发行方式：安装版（可启用智能记录组件）与便携版

桌面版自 V3.1.15 起只发布一个版本：

* **安装版**：主程序不含智能记录。打开「智能记录」页可一键下载与当前程序版本配套的 **AI 组件包**（组件程序 + 转写/生成引擎，约 60 MB），下载安装后即获得完整的离线智能记录功能；模型文件在组件内按需单独下载。组件只存放在本机数据目录，可随时删除，删除不影响任何工作数据。组件包随每个版本发布在本仓库的 GitHub Release 中（文件名形如 `ai-components-v<版本>-windows.zip` / `-macos.zip`）。
* **便携版**：与安装版同一个程序，但便携模式下不提供智能记录——没有智能记录入口，也不能安装组件；其余功能（来访者、咨询记录、日程、收费、模板、合规等）与安装版完全相同，适合 U 盘随身或明确不使用 AI 辅助记录的场景。

程序升级到新版本后，旧版本组件不再匹配，需要在智能记录页重新下载新版组件（模型文件不受影响，无需重下）。

## 智能记录（离线 AI）

桌面版内置「智能记录」页，两种用法，全程在本机离线完成，音频与文本不上传任何服务器：

* **模式一 · 咨询录音转写**：取得来访者同意后，在咨询中直接录音（或导入已有音频文件），由本机语音转写引擎转成文字稿；可编辑转写稿，转写后可自动删除原录音。
* **录音来源（线下 / 远程）**：录音前可选择「线下面对面 · 麦克风」或「远程咨询 · 麦克风 + 系统音频」。远程模式开始录音时会请求共享整个屏幕并混录系统音频（来访者的声音），共享的视频立即丢弃、不保存也不上传；系统不支持直接捕获系统音频时（如 macOS），可安装 BlackHole 等回环设备、将通话音频路由到该设备并选为音频输入。音频输入设备可从设备列表中选择（选择会记住），点「刷新设备」可重新读取设备名称。
* **模式二 · 小结生成记录**：咨询后输入几句简要小结，由本机语言模型生成结构化咨询记录草稿。
* 两种模式共用生成管线：选择来访者、日期与笔记模型（可选参考记录模板）→ 生成后自动打开记录编辑框并填好草稿字段（主题 / 重要内容 / 咨询师工作 / 来访者反应 / 计划 / 下次关注）。**草稿不会自动保存**，必须由咨询师核对修改后手动保存。
* **多语言**：转写语言可选 22 种（普通话、粤语、英语、西班牙语、日语、韩语、法语、德语等，或自动检测），并新增 large-v3-turbo 转写模型；**输出语言可单独选择**（跟随输入语言，或简体中文、繁體中文、English、Español、日本語、한국어 等 12 种），转写用什么语言、记录写成什么语言互不绑定。
* **记录格式**：生成结构可选标准六字段、SOAP、DAP、BIRP（DAP / BIRP 为新增内置模板）；可填写咨询取向 / 风格（如 CBT、人本主义），生成时体现在表述中。
* **临床语言语料库（中文）**：生成时自动注入标准临床书面语的句式参考（呈现、评估与进展、干预、反应、计划），使草稿表述自动靠拢规范临床书面语；干预句式按所填取向 / 风格匹配一组（CBT、心理动力学、创伤知情、DBT、动机式访谈、成瘾、行为、家庭，未填时默认支持性／人本）；另按转写稿 / 小结原文的关键词自动匹配最多两组「问题聚焦」句式（焦虑、抑郁、愤怒、哀伤、强迫、关系、自尊、家庭、育儿、惊恐、物质使用），无关键词命中时不添加。收藏与自建的个人句式（见「我的句式」）会附在语料库末尾，内容相符时优先采用。语料库只提供句式、且仅在转写稿或小结内容有依据时采用，不会据此添加未实际发生的干预、症状或进展；自定义模板 / 指令仍优先于语料库。结构与匹配规则见 `CORPUS.md`。
* **自定义模板 / 指令**：可直接输入或粘贴自己的记录模板与写作要求（自然语言即可），自动保存在本机，生成时优先遵循。
* **转写稿说话人标记**：一键在光标处插入「咨询师：」「来访者：」标记；可设置记录保存后自动清除本页转写稿与小结。
* **录音知情同意书**：智能记录页可一键打印中英双语同意书（本地处理、删除安排、随时撤回等条款），交来访者签署。

首次使用需要在「智能记录」页下载引擎与模型（转写模型约 150 MB–1.5 GB、笔记模型约 1.1–2.1 GB，可按速度与质量选择），下载完成后完全离线。也支持导入已手动下载的模型文件与自定义引擎路径；macOS 的转写引擎可通过 Homebrew 安装（brew install whisper-cpp）后自动识别。长录音的转写与生成在本机 CPU 上需要一些时间，页面会显示进度并可取消。
