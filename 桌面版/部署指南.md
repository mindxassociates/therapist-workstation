# 心理咨询师工作台 — 部署指南（V3.1.6）

## 你只需要做一件事

在要构建的电脑上，运行对应系统的一键脚本。缺失的开发工具脚本会**自动安装**，构建完成后会自动打开 `release/` 文件夹，里面就是可以发给咨询师的安装包。

| 系统 | 运行 | 产物（在 `release/` 里） |
| --- | --- | --- |
| Windows | 双击 `build-windows.bat` | `TherapistWorkstation-3.1.6-Windows-Setup.exe` |
| macOS | 双击 `build-macos.command`（或在终端里运行） | `TherapistWorkstation-3.1.6-macOS.dmg` |

首次构建需要下载并编译依赖（包括加密数据库），通常 10–30 分钟，取决于网速和机器；之后再构建会快很多。脚本中途如果提示安装了大型工具后需要重跑，照做一次即可。

## 发给咨询师时怎么说

- **Windows**：运行安装包即可。SmartScreen 若提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」（因为安装包没有购买代码签名证书）。
- **macOS**：打开 `.dmg`，把应用拖进「应用程序」。首次打开请**右键点击应用 → 打开**，或在「系统设置 → 隐私与安全性」里点「仍要打开」（同样因为未做 Apple 签名；如需正式分发，需 Apple Developer ID 签名 + 公证）。
- **数据不在安装包里**：数据只存在每台电脑自己的应用数据目录中，加密保存，不会随安装包传播。

## 升级到新版本

直接在新电脑/原电脑上安装新版安装包即可覆盖升级，**原有数据不受影响**（数据目录与程序分离）。升级前建议先在应用「数据中心」里做一次手动备份。

## 数据位置（排障用）

- Windows 标准模式：`%LOCALAPPDATA%\us.mindx.therapistworkstation\Data / Backups`
- macOS 标准模式：`~/Library/Application Support/us.mindx.therapistworkstation/Data / Backups`
- 便携模式：在程序文件旁放一个空文件 `portable.mode`，数据改存在程序同目录的 `Data` 文件夹。

## 验证安装包完整性

`release/` 里的校验和文件可用于核对文件在传输中未被篡改：Windows 看 `.sha256.txt`，macOS 看 `SHA256SUMS.txt`。

## 便携版（免安装）

构建时会自动同时产出便携包（与安装包版本号、校验和一并放在 `release/`）：

| 系统 | 便携包 | 用法 |
| --- | --- | --- |
| Windows | `TherapistWorkstation-3.1.6-Windows-Portable.zip` | 解压到任意文件夹或 U 盘，双击 `TherapistWorkstation.exe` |
| macOS | `TherapistWorkstation-3.1.6-macOS-Portable.zip` | 解压后保持 `portable.mode` 与 `.app` 在同一文件夹，双击 `.app` |

便携版的数据（加密数据库 + 自动备份）保存在程序同文件夹的 `Data` / `Backups` 里，整个文件夹可以搬走。注意事项都在便携包内的《便携版说明.md》里：退出程序后再拔 U 盘、不要放云盘同步目录、保管好介质与密码。找不到 `portable.mode` 时，程序会自动回退到这台电脑的固定数据目录；便携目录不可写（如只读 U 盘）时也会自动回退，不会启动失败。
