# 心理咨询师工作台（Therapist Workstation）

**专为在中国大陆执业的心理咨询师设计**——面向个人执业、自由执业与小型工作室的本地优先个人工作台，把来访者档案、咨询日程、咨询记录、咨询方案、任务、收费、随手记和专业转介资源整合到一个工作空间中，减少在日历、文档、表格和便签之间反复切换。

## 为中国大陆执业场景做的设计

* 全中文界面与中文记录模板，不以美国保险理赔、CPT 或强制诊断体系作为记录框架
* 默认北京时间，日期统一使用 `YYYY-MM-DD` 格式并通过日期选择器录入
* 收费以人民币计价，付款方式包含微信、支付宝、银行转账与现金
* 咨询方式使用大陆常用表述：视频、面询、电话
* 安全与危机资源为大陆号码：110、120、全国统一心理援助热线 **12356**、希望24热线 400-161-9995
* 依《个人信息保护法》设计：心理健康信息属于敏感个人信息，建档清单内置「敏感个人信息单独同意」，并提供可打印的《个人信息处理告知》模板
* 本地优先：数据保存在自己的设备上，不上传服务器，不做数据分析或广告

## 具体功能（两版共有）

### 今日工作台
今日咨询、今日待办、待收费、待补咨询记录、建档未完成事项与近期工作概览集中在首页，统计可直接点击进入对应功能区。

### 来访者管理
* 基本资料、出生日期、性别、联系方式、主要议题、首次咨询日期与备注
* 建档清单：知情同意书、付款方式、联系方式、紧急联系人、数据保存及隐私说明已告知、**敏感个人信息单独同意已取得**、紧急情况处理规则已说明，并可添加自定义建档项目
* 咨询方案：开始日期、预计周期、咨询目标与工作重点
* 来访者归档与恢复；档案导出（导出前有明文提醒）；**彻底删除**（级联删除该来访者的全部关联数据，响应来访者的删除请求）
* 安全与危机资源弹窗（110 / 120 / 12356 / 400-161-9995）

### 日程管理
月视图与周视图；心理咨询、会议、个人事项等类型；关联来访者；视频 / 面询 / 电话；可设时区与重复日程；咨询日程可直接生成咨询记录并关联收费。

### 咨询记录
* 以自由书写为默认方式，提供富文本编辑区域，不强迫固定格式
* 草稿自动保存（仅保存为草稿，不会误标为已完成），可从前次咨询记录复制
* 待补记录识别：已结束但未写记录的咨询会自动列入「待补记录」
* 可打印或保存为 PDF，打印页尾可显示机构或工作室名称

### 中文参考模板与常用语
可选的首次咨询 / 初始评估、结构化咨询记录等中文参考模板；内置情绪与主观状态、咨询师观察、咨询过程与干预、来访者反应、咨询进展、后续计划、风险与安全等常用记录用语，也可建立自己的常用文字与自定义模板。

### 任务看板
* 待处理 / 进行中 / 等待中 / 已完成四列，拖拽或下拉切换状态，可关联来访者
* 子任务清单：卡片上直接勾选，显示完成进度
* 分类与自动归类：咨询记录、来访者跟进、行政事务、财务收费、督导学习、其他
* 重复任务（每周 / 每两周 / 每月），完成后自动生成下一次
* 列内按截止日期排序，卡片标注「已逾期 N 天」「今天到期」，可按逾期 / 今日 / 本周、分类、来访者筛选
* 已完成任务保留 14 天后自动归档，可在归档页恢复或删除

### 咨询目标与随手记
按来访者维护咨询目标与进展；随手记为便签式卡片，支持置顶、搜索、标签与颜色，用于记录不适合放入正式咨询记录的工作信息。

### 收费管理
金额、日期、待收 / 部分收款 / 已收状态，微信、支付宝、银行转账、现金等付款方式；今日工作台自动汇总待收费，可一键标记已收。

### 转介网络
维护自己的专业转介资源库（咨询师、精神科医生、心理学家、社区资源等）：姓名 / 机构、专长、地区、联系方式、备注；支持搜索，并可把转介资源关联到来访者。

### 全局搜索、归档与数据
一个入口搜索来访者、咨询记录、日程、任务、随手记、目标、收费、模板与转介；归档页集中管理已归档来访者与任务；数据中心提供完整备份导出 / 恢复与数据健康检查。

### 隐私与合规
「隐私与合规」页说明本产品的数据处理方式（本地保存、不上传、敏感个人信息与单独同意、不满 14 周岁须监护人同意、影响评估与安全事件处置要点、《精神卫生法》保密义务），并附可打印的《个人信息处理告知》模板（自动带入设置中的机构与咨询师姓名，含来访者或监护人签署行）。来访者档案的导出与彻底删除用于响应查阅、复制与删除请求。

### 模板系统
模板分三类：咨询记录模板、咨询方案模板、通用模板。内置首次咨询 / 初始评估、结构化咨询记录、SOAP 记录、阶段性咨询方案、安全计划等模板；内置与自建模板都可新增、编辑、删除（网页版内置模板可隐藏并恢复），写记录与做方案时可直接套用。

### 个性化设置
主题色（默认品牌色 `#4a778b` 门户蓝灰，另有多种预设与自定义取色）、浅色 / 深色主题、字号（小 / 标准 / 大）、界面密度（舒适 / 紧凑）、标题栏风格（极光渐变 / 纯色深青 / 浅色简洁）、打开时默认页面、首页模块显示开关（今日咨询、待办、待收费、建档未完成等可分别隐藏），并可一键恢复默认外观。网页版另可自定义工作台图标。

### 临床与运营功能
* **量表评估**：PHQ-9、GAD-7 中文版，自动计分与严重程度分级，第 9 题阳性自动提示关注自伤风险，可看较上次变化
* **候补名单**：登记等待空缺的潜在来访者（议题、期望时段、来源），按状态分组，一键转为正式档案
* **日程状态与着色**：已确认 / 已完成 / 爽约 / 迟到取消 / 已取消五档，月历按状态着色；可保存视频会议链接
* **收费对账单**：按来访者与时间段生成（咨询次数、收费明细、应收 / 已收 / 未收），可打印或存为 PDF
* **数据洞察**：咨询场次、实收与待收、爽约统计、咨询量 Top 来访者、近 6 个月实收趋势
* **文档追踪**：在档案中记录知情同意书、个人信息处理告知等文件的待签署 / 已签署 / 已发送状态
* **默认收费标准**：每位来访者可设默认收费，新建收费记录时自动带入

## 网页版（V1.14.0）

* 单文件 HTML：无需安装、无需服务器，下载后用现代浏览器打开 `网页版/index.html` 即可使用
* `网页版/pwa/`：可安装到电脑桌面或手机主屏幕，首次联网载入后可离线打开
* 数据保存在浏览器本地存储中，提供访问密码锁定与无操作自动锁定
* 注意：浏览器本地存储不做静态加密，请只在个人设备上使用并定期导出备份；导出的文件为明文，请勿存入云盘、网盘或境外服务器
* 历史版本（V1.10.3 – V1.10.6）存档于 `网页版/versions/`，仅供查阅，不再维护
* 详细功能说明见 `网页版/README.md`；冒烟测试见 `网页版/tests/`

## 桌面版（V3.1.6）

* 加密数据库存储（SQLCipher），数据只保存在本机；本地多账户与管理员 / 咨询师角色，各账户以自己的密码解锁同一数据库
* 登录失败节流、无操作自动锁定、改密与账户管理；登录、锁定、备份、导出、删除等操作写入防篡改审计日志
* 每日首次登录自动生成加密备份（保留最近 30 份），另可手动备份与恢复
* 构建脚本自动安装缺失工具并校验版本，构建后同时产出**安装版**与**免安装便携版**（数据保存在程序同文件夹，可整体放在移动硬盘或 U 盘上使用）
* 工作室 Logo 上传与文档版式定制：分享给来访者的收费对账单、个人信息处理告知等文档可选用品牌横幅 / 简洁 / 极简页眉，并可显示联系方式与页脚文字
* 构建方法见 `桌面版/部署指南.md`，产品与架构说明见 `桌面版/README.md`，变更记录见 `桌面版/CHANGELOG.md`
