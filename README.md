# 心理咨询师工作台 · Therapist Workstation

专为**中国大陆私人执业心理咨询师**设计的本地优先个人工作台：来访者档案、咨询日程、咨询记录、咨询方案、任务看板、收费、随手记与专业转介资源，整合在一个工作空间中。英文产品名统一为 **Therapist Workstation**。

本仓库包含两个版本，功能与视觉保持对齐（同一套 Provider Portal 深青品牌配色）：

## 📁 网页版/（V1.11.0）

单文件 HTML + PWA，无需安装、无需服务器，用现代浏览器打开 `网页版/index.html` 即可使用；`网页版/pwa/` 提供可安装到桌面/手机主屏幕、支持离线打开的 PWA 外壳。数据保存在浏览器本地存储中（不上传、无中心服务器），并提供访问密码锁定、完整备份导出/恢复。

- 功能与使用说明见 [`网页版/README.md`](网页版/README.md)
- 历史版本快照在 `网页版/versions/`（V1.10.3 – V1.10.6，仅存档，不再维护）
- 冒烟测试：`网页版/tests/web-smoke-test.cjs`（需 jsdom）

> 网页版的浏览器本地存储不做静态加密。请只在个人设备上使用，并定期导出备份；导出的文件为明文，不要存入云盘、网盘或境外服务器。

## 📁 桌面版/（V3.1.3）

Tauri 2 + SQLCipher 加密数据库的 Windows / macOS 桌面应用：本地多账户与角色、登录节流、无操作自动锁定、防篡改审计日志、每日自动加密备份，数据不出本机。构建脚本会自动安装缺失工具并同时产出**安装版**与**免安装便携版**（数据保存在程序同文件夹，可放 U 盘/移动硬盘）。

- 构建与分发：见 [`桌面版/部署指南.md`](桌面版/部署指南.md)（Windows 双击 `build-windows.bat`，macOS 运行 `build-macos.command`）
- 产品说明：[`桌面版/README.md`](桌面版/README.md)；变更记录：[`桌面版/CHANGELOG.md`](桌面版/CHANGELOG.md)

## 隐私与合规

两个版本均按《个人信息保护法》对敏感个人信息的处理要求设计：建档清单内置「敏感个人信息单独同意」，内置「隐私与合规」说明页与可打印的《个人信息处理告知》模板，支持来访者数据导出与彻底删除。相关内容为产品功能说明，不构成法律意见；本产品不宣称任何合规认证。
