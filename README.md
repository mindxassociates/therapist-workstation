心理咨询师工作台

心理咨询师工作台是一个专为**中国大陆私人执业心理咨询师**设计的轻量、本地优先个人工作台。

项目希望把私人执业中分散的日常事务——来访者资料、咨询日程、咨询记录、咨询方案、任务、收费、随手记和专业转介资源——整合到一个简单的工作空间中。

当前版本采用**单文件 HTML** 形式，无需安装专门软件或部署服务器，使用现代浏览器即可打开。数据主要保存在当前浏览器的本地存储中。

---

## 主要功能

### 🏠 今日工作台

将当天最需要关注的信息集中到首页，包括：

* 今日咨询
* 今日待办
* 待收费
* 待补咨询记录
* 建档未完成事项
* 近期工作概览

相关统计可以直接进入对应功能区，减少在不同页面之间反复查找。

### 👤 来访者管理

建立和维护个人来访者档案，包括：

* 基本资料
* 出生日期
* 性别
* 联系方式
* 主要议题
* 首次咨询日期
* 备注
* 建档清单
* 自定义建档项目
* 咨询方案
* 来访者归档

日期统一采用中国大陆较常见的 `YYYY-MM-DD` 格式。

### 📅 日程管理

用于管理心理咨询和其他工作安排：

* 月视图 / 周视图
* 心理咨询、会议、个人事项等日程
* 关联具体来访者
* 视频 / 面询 / 电话
* 时区设置
* 重复日程
* 点击日期快速新增日程
* 从咨询日程直接进入相关咨询记录

心理咨询日程还可以与收费记录关联。

### 📝 咨询记录

咨询记录默认采用**自由书写（Free Text）**模式，提供较大的富文本编辑区域，不强迫咨询师使用固定格式。

支持：

* 富文本编辑
* 自动保存草稿
* 从前次咨询记录复制
* 与来访者及咨询日程关联
* 待补咨询记录识别
* 打印 / 保存为 PDF
* 自定义打印页尾机构或工作室名称

### 📋 中文参考模板

对于希望使用结构化记录的咨询师，提供可选参考模板，包括：

* 首次咨询 / 初始评估
* 结构化咨询记录

模板针对中国大陆私人心理咨询实践进行了调整，不以美国保险理赔、CPT 或强制诊断体系作为记录框架。

模板只是辅助工具，**Free Text 仍然是默认记录方式**。

### ✍️ 常用记录用语

咨询记录编辑器内置常见专业记录用语，可按需要快速插入，例如：

* 情绪 / 主观状态
* 咨询师观察
* 常见咨询议题
* 咨询过程 / 干预
* 来访者反应
* 咨询进展
* 后续计划
* 风险与安全相关记录

同时支持建立自己的常用文字。

风险相关文字仅作为记录辅助，应根据实际评估结果使用，不应作为默认临床结论。

### 📑 自定义咨询记录模板

除了内置参考模板，也可以建立适合自己工作方式的记录模板。

适用于希望长期使用自己机构格式、特定理论取向记录结构或其他个人记录习惯的咨询师。

### 💰 收费管理

记录私人执业中的收费情况，包括：

* 金额
* 日期
* 待收 / 已收等状态
* 微信支付
* 支付宝
* 银行卡 / 转账
* 现金
* 信用卡 / 借记卡
* 保险
* 其他付款方式

心理咨询日程可以直接关联收费记录，减少日程与账目之间的重复录入。

### ✅ 任务看板

采用看板方式管理工作任务：

* 待办
* 进行中
* 已完成
* 拖曳更新任务状态
* 编辑任务详情
* 设置日期
* 关联具体来访者
* 今日到期任务自动进入今日工作台

既可以记录来访者相关事项，也可以管理私人执业中的一般行政任务。

### 💡 随手记

提供类似便签的瀑布流卡片，用于记录不适合放入正式咨询记录的个人工作信息。

支持：

* 标题
* 内容
* 标签
* 卡片颜色
* 瀑布流显示
* 搜索

### 🤝 转介网络

建立属于咨询师自己的专业转介资源库，例如：

* 心理咨询师
* 精神科医生
* 心理学家
* 初级保健医生
* 物质使用相关服务
* 更高等级照护资源
* 社区资源
* 其他专业服务

可以记录：

* 姓名 / 机构
* 专长领域
* 地区
* 联系方式
* 接受的保险
* 备注

支持搜索、编辑、导出 CSV 以及打印 / 保存 PDF。

### 🔎 全局搜索

从一个入口搜索工作台中的不同信息，包括：

* 来访者
* 咨询记录
* 任务
* 随手记
* 转介网络等

减少在不同模块之间逐个查找资料的需要。

### 📦 数据备份与恢复

工作台数据保存在浏览器本地。

支持数据备份与恢复，便于：

* 定期备份
* 更换设备前保存数据
* 保存独立的数据副本

**清除浏览器数据、浏览器故障或设备损坏都可能导致本地数据丢失，因此建议建立自己的定期备份习惯。**

### 🎨 个性化设置

可以根据个人执业习惯调整工作台，例如：

* 工具名称
* 机构 / 工作室名称
* 工作台图标
* 主题色
* 深色模式
* 打印文件显示信息

## 为什么做这个项目？

中国大陆越来越多心理咨询师采用个人执业、自由执业或小型工作室形式工作，但日常管理工具往往分散在日历、Word、Excel、便签、收费表和不同平台之间。

心理咨询师工作台希望提供另一种思路：

**不追求复杂的大型管理系统，而是把心理咨询师每天真正会用到的工具放在一个简单的个人工作台里。**

它尤其关注：

* 中文使用体验
* 中国大陆私人执业场景
* 简单易用
* 较低的技术门槛
* 本地优先
* 数据可备份、可迁移
* 尽量减少重复录入

---

## 本地优先

心理咨询师工作台 当前版本采用单文件 HTML 架构，核心数据保存在使用者当前浏览器的本地存储中。

这意味着它与传统云端 SaaS 的工作方式不同：

**没有账号系统，没有中心服务器，也不会因为打开这个 HTML 文件就自动把工作台数据上传到项目开发者。**

但“本地保存”本身并不等同于满足任何特定的数据安全、隐私、医疗信息或专业合规标准。

使用者仍需要自行考虑设备安全、浏览器安全、访问控制、数据备份以及所在地适用的法律法规和专业伦理要求。
