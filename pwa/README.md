# 心理咨询师工作台 PWA

这是主项目的 Progressive Web App（PWA）版本。它保留现有单文件工作台的功能与浏览器本地存储方式，同时增加：

- 可安装到桌面或手机主屏幕
- 独立应用窗口（standalone）
- Service Worker 离线缓存
- Web App Manifest
- 普通与 maskable 应用图标
- GitHub Pages 子目录兼容的相对路径

## 使用

通过 HTTPS 或 localhost 访问 `pwa/` 目录。首次访问需要联网，以便缓存 PWA 外壳和主工作台文件。首次成功载入后，支持离线重新打开。

PWA 外壳会读取仓库根目录的 `index.html`，因此主工作台仍然保持单一功能源，避免 PWA 副本与根版本长期产生功能分叉。

## 数据说明

工作数据仍保存在浏览器的本地存储中。安装为 PWA 不会自动将数据上传到服务器，也不等同于数据库级加密、医疗信息安全认证或任何特定地区的合规保证。

请继续使用工作台内的数据备份功能，并根据实际执业环境采取适当的设备安全、访问控制和备份措施。
